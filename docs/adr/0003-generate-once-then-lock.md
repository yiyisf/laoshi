# 0003 适配器只在安装时生成一次并锁定

- 状态：提议
- 详见：[init-bootstrap.md](../design/init-bootstrap.md)

## 背景

"让核心能力根据所处平台自己长出来"有价值：新平台接入成本低。但如果每次运行都由模型现场决定如何调用平台，流程就不再可控、不可复现，和本项目"AI 和人都不即兴发挥"的目标冲突。内网模型能力也较弱，现场生成风险更高。

## 决定

- 适配器由内置 skill **在安装时**借助 LLM 探测与生成，经人确认后**锁定**（`laoshi.adapter.lock.json`：平台版本、laoshi 版本、生成物哈希、探针结果、确认记录）。
- 运行时只执行锁定版本；`doctor` 校验哈希，平台或 laoshi 版本变化时标记过期。
- 优先生成**声明式适配器描述**（数据），由通用解释器执行；描述表达不了时才生成代码，并要求更严格的审阅。
- 能力有没有，以**探针测试**的真实结果为准，不以模型的判断为准。

## 影响

- 需要先写探针集和描述解释器；内部平台的真实接口形态决定声明式方案是否够用。
- 生成物视同代码，必须经人确认；锁定文件放机器配置目录，不放项目仓库。
